Tactical Comms Planning Manual

1. Terrain-Aware Physics

This planner uses Highest Accuracy 3D Line-of-Sight simulation. Unlike basic range circles, the "coverage blooms" represent the actual physical reach of the signal.

  • Hill Shadows: If a unit is behind a ridge line from the transmitter, signal will be blocked even at short ranges.
  • Foliage Loss: Forested and Urban areas introduce significant signal attenuation. Expect 40-70% range reduction in dense bush.

2. Network Hierarchy

  • Unassigned Pool: Markers dragged onto the map start here. They are not part of any frequency plan yet.
  • Nets: Create a Net (e.g., PLT NET) and drag units into it. The system will automatically check if their equipment (SAT vs VHF) matches the PACE plan.
  • Sweep Entire Net: Use this button inside a Net box to see the combined coverage of every unit in that structure.

3. PACE Matrix & Environmental Sandbox

The PACE Matrix updates in real-time as you move units or edit frequencies. If a unit is assigned a SATCOM link but only carries a Handheld VHF radio, a CAPABILITY MISMATCH warning will appear in the Analysis board.

Environment Sliders: Use these to simulate "What-If" scenarios like heavy salt storms or nighttime VHF propagation drops without affecting the live server.
