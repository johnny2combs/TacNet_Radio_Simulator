User Manual & System Guide

Comprehensive guide to configuring, operating, and managing the TacNet simulation suite

0. Before You Begin 🟢

TacNet requires three separate executables working together. Ensure your environment meets these minimums:

  • OS: Windows 10/11 (64-bit) or Linux (Wine/Proton compatible)
  • Network: Open 5000 TCP & 5005 UDP on your firewall/router
  • Audio: Functional microphone & headset (Push-To-Talk requires a working input device)
📦 Installation Order & First Run
  1. Install TacNet-Server.exe first. Run it as Administrator.
  2. Install TacNet-Client.exe on all operator machines.
  3. Place TacNet-Launcher.exe in a shared folder or distribute via Discord/email.
  4. On first launch, allow Windows Defender / AV exceptions if prompted.

1. System Architecture

TacNet is a decentralized client-server tactical radio simulation designed to replicate real-world RF (Radio Frequency) physics, environmental effects, and military hardware limitations.

  • The Server: This acts as the "world engine." It does not transmit audio itself, but rather computes the physics (terrain occlusion, distance, weather, electronic warfare) and routes audio packets between clients.
  • The Client: The interface used by the actual operators. It captures microphone input and plays back incoming audio based on the server's physics calculations.
  • The Launcher: A lightweight utility that allows operators to easily connect their client to your server IP address.

2. Getting Started: First Simulation 🚀

Follow these steps exactly in order. A misstep here is the #1 cause of "I can't connect" issues.

  1. Create a Hardware Profile
    • Open Server → Profiles tab → Click + New Profile
    • Name it clearly (e.g., PRC-152_Handheld)
    • Set Freq Range (e.g., 30-512 MHz), Tx Power (5W), Sensitivity (-110 dBm)
    • ✅ Tip: Click Test Range to verify coverage before saving.
  2. Define Your Comms Plan
    • Go to Comms Plan tab → + New Channel
    • Name: Command Net | Freq: 45.500 MHz | Mode: FM
  3. Register Callsigns
    • Go to Callsigns tab → + New Callsign
    • Enter exact name (e.g., ALPHA) → Assign profile → Check Command Net
    • ⚠️ Warning: Callsigns are case-sensitive.
  4. Connect Clients
    • Operators run TacNet-Launcher.exe, enter IP and Callsign, then click Connect.

3. Quick Troubleshooting 🔧

Audio cuts out / static Terrain block Check Signal Quality. Deploy a RETRA node.
"Connection refused" Firewall issue Open ports 5000 TCP & 5005 UDP.
📘 Beginner Glossary
  • Squelch Floor: Min signal strength needed for audio.
  • RETRA: Retransmission repeater node.
  • EMCON: Emission Control (Radio Silence).
  • H-Hour: Official mission start time.
  • Diffraction: Signal loss from terrain obstacles.

5. Advanced Hardware Profiles ⚙️

TacNet simulates specific radio hardware. In the Profiles tab, you can edit granular RF parameters:

  • Freq Range & Band: Ensures the radio can tune to the assigned net.
  • Tx Power (Watts): Higher wattage pushes through weather and distance.
  • Modulation Sensitivity (dBm): Determines the "squelch floor." A lower number (e.g., -120 dBm) is more sensitive.

6. Tactical Map & Infrastructure

The Tactical Map visualizes unit locations. Distance and terrain block radio signals.

  • Moving Units: Manually drag icons to update positions if GPS is not enabled.
  • Retransmission Nodes (RETRA): Deploy nodes on high ground to bridge communications over terrain.

7. Physics & Environment Engine

TacNet applies real-world physics to every transmission.

  • Terrain (Line of Sight): Uses SRTM elevation tiles to calculate diffraction and occlusion.
  • Weather Effects: Rain and storms increase the electromagnetic noise floor.
  • Day/Night Cycle: Solar radiation affects D-Layer ionospheric absorption for HF signals.

8. Electronic Warfare (EW) 🛡️

The Electronic Warfare tab allows you to attack the communications network.

  • Signal Degradation (EMI): Injects background static into specific channels.
  • Area Jamming: Bombards frequencies with noise, causing packet loss and choppy audio.
  • EMCON: Completely suppresses PTT for targeted units.

9. After-Action Review (AAR)

Manage exercise recordings and transmission logs.

  • Recording: Logs every transmission with timestamps, callsigns, and signal quality.
  • H-Hour Sync: Synchronize the recording timeline to real-world or mission-specific time.

10. Network Topology Mesh 🌐

The Topology tab provides a real-time visualization of the RF network mesh, showing how nodes are interconnected and where signal bottlenecks occur.

  • Mesh Visualization: Lines between nodes indicate signal strength (Strong, Medium, Weak). Moving lines indicate active data or voice traffic.
  • Diagnostic Controls:
    • Fit View: Automatically centers and scales the map to show all active nodes.
    • Reset: Returns the view to the default scale and center position.
    • Node Stats: Real-time count of active Clients and Infrastructure (Retrans) nodes.
  • Node Telemetry: Click any node on the map to view its specific frequency, MGRS coordinates, and neighbor list in the side panel.

11. Advanced Tactical Features & Mesh Diagnostics ⚡

TacNet features seven advanced combat operations enhancements developed to model professional communications networks:

  • Spacebar Focus Intercept (PTT Guard): When operating the client, pressing Spacebar activates Push-To-Talk. An advanced global event filter automatically intercepts the spacebar press, ensuring that if you are currently typing in a text input field, spacebar behaves as a normal character, but in any other area of the screen, the spacebar PTT is consumed cleanly without triggering accidental clicks on highlighted channel buttons.
  • COMSEC Keyfills & Decryption Screech: Secure channels now utilize password-masked cryptographic passphrases defined in the Comms Plan. If a client attempts to communicate without a matching keyfill, the server rejects the key mismatch and plays back a loud, vector-synthesized LFO digital modem screeching sound to warn the operator of the COMSEC fault. In emergencies, clicking the red-bordered ZEROIZE button in the settings clears all channel keys globally and dynamically alerts the server mesh.
  • RETRANS BFS Mesh Routing: Extends radio coverage over large grids by establishing undirected mesh connections via deployed retransmission nodes. The server automatically runs a Breadth-First Search (BFS) algorithm to route packets dynamically across all linked channels. A loop-prevention guard ensures audio does not feed back by tagging relayed packets with a " [R]" callsign suffix.
  • Split-Ear Spatial Audio: A high-performance stereo audio panning algorithm. When enabled in the general settings:
    • Primary Channel traffic is routed entirely to the Left Ear.
    • Monitored Channels traffic is routed entirely to the Right Ear.
    • General / Unknown traffic is mixed at $0.707\times$ constant power to Both Ears.
    • Disabling spatial audio seamlessly collapses both channels back to a robust mixed-mono dual-ear output.
  • Vehicle Intercom (CH99 VIC): A local-wire intercom system. Any transmissions on CH99 bypass all terrain calculations, GPS degradation, and atmospheric attenuation factors, forcing a 100% stable ($1.0$ signal) connection for crew intercom simulation.
  • Tactical Viewshed Coverage Heatmaps: Located in the Tactical Map tab. Selecting an active transmitter from the dropdown and clicking ▶ Run Viewshed initiates a POST request that simulates the radio's precise coverage. It projects HSL-colored rectangle cells onto the map based on terrain and weather attenuation:
    • Green Cells (≥80%): Strong signal coverage.
    • Amber Cells (≥40%): Marginal signal (static/choppiness likely).
    • Red Cells (<40%): Weak signal / connection dropout.
  • Command Telemetry HUDs: Four premium diagnostics cards placed directly on the main Dashboard tab:
    • Atmosphere & Terrain HUD: Live progress meters tracking rain attenuation, urban attenuation, multipath echoes, and active solar ionosphere storms.
    • EW & Threat Board: Dynamic tracking of OPFOR RF jammers, active threat counts, urban EMI levels, co-site risks, and silenced EMCON nodes.
    • LQA Matrix: Live grid detailing all mutual direct/mesh link path states, geographical distances, and signal percentages.
    • PACE Plan Auditor: Audits all connected callsigns to warn of missing loadout components (e.g. SATCOM or HF band assigned without matching hardware antenna) and checks COMSEC key fills.

Pro Tips

  • Check Your Ranges: Check the Signal Quality tab if operators report issues.
  • Use Retrans Nodes: Deploy nodes strategically on high ground.
  • Mesh Health: Use the Topology tab to identify dead spots in your mesh. A "Weak" link often indicates upcoming communication drops.
  • Fit View: If you lose track of nodes after panning, use Fit View in the Topology sidebar to quickly re-center.
  • Monitor Dashboard: Real-time view of packet drops and jamming impact.
  • Export Plans: Save your CEOI as a JSON file for quick restoration.
