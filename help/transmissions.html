Active Transmissions Board

Live audio telemetry and RF status monitoring.

1. Operational Signal Statuses
Every unit actively connecting to the TacNet server is tracked here:
  • TX (Transmitting): Pulsing green indicator. The operator is currently holding Push-To-Talk (PTT) and broadcasting audio.
  • RX (Receiving): Pulsing blue indicator. The unit is currently receiving relayed audio from another transmitter.
  • IDLE: Standard gray border. The node is online, authenticated, and monitoring channels, but no traffic is currently active.
2. Real-time Transmission Telemetry
Each active card details critical physical constraints:
  • Channel ID: The active frequency net currently tuned in.
  • Duration: Active transmission timer in seconds.
  • LQA Signal Bar: Multi-bar real-time Signal Quality indicator (Red/Amber/Green). Shows the received SINAD/Clarity metric.
  • Path Details: Indicates direct LOS connections, hops count through mesh nodes, or satellite latencies.
Did you know? You can use the search bar in the Comms Plan or use filters on the Tactical Map to trace unit locations if a connection displays weak or degraded.
