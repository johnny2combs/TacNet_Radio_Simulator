Tactical Map

Real-time geographical tracking of clients and infrastructure.

1. Live Tracking
Operators using the SWORD ATAK integration will automatically report their GPS positions here. If operators are manual, you can left-click and drag their blue icons to estimate their location for the physics engine.
2. Interactive Tools
  • Ruler Tool: Right-click to measure exact distance and bearing between two points.
  • LOS Tool: Right-click and drag between two units to generate a terrain profile chart. This instantly shows if a mountain is blocking their transmission path.
3. Moving Infrastructure
Retrans nodes (yellow triangles) can be freely dragged around the map to optimize network coverage based on the terrain.
4. Viewshed Coverage Heatmap Sweeps
Audit mesh connectivity and signal envelopes using the Viewshed control panel:
  • Run Viewshed: Select any online unit or retrans node from the dropdown list and click ▶ Run Viewshed. The server simulates a high-accuracy 3D terrain sweep taking into account the node's transmit power, antenna height, and loadout specs.
  • Signal Overlay Cells: Green, amber, and red cells are projected directly on the Leaflet map showing signal strength tooltips. Click ✕ Clear Overlay to purge the heatmap display.
