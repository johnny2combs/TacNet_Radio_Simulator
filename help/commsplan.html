Comms Plan Manager

Global registry of authorized channels and callsigns (CEOI).

1. Channel Plan
Define the available radio nets for the exercise. Each channel requires a unique frequency and an optional encryption passphrase. Clients can only see and join channels that they are authorized for in the Callsign Register.
2. Callsign Register
Create accounts for every operator.
  • Callsign: Must exactly match what the operator types into their Launcher to connect.
  • Unit / Role: Organizational metadata (e.g., 'Alpha Platoon Commander').
  • Authorized Channels: A critical security feature. If a callsign does not have 'CH2' selected here, they cannot tune their client to CH2.
3. Importing / Exporting JSON
Building a CEOI for 50 players takes time. Use the Export JSON button to save your entire Comms Plan locally. For future exercises, simply Import JSON to restore all channels and callsigns instantly.
4. COMSEC Security & Bypass Channels
TacNet supports mission-grade encryption and specialized wire intercoms:
  • COMSEC Keyfill: Encrypted channels require a valid passphrase. If an operator attempts to transmit without the correct keyfill, their audio is muted and replaced by an LFO digital screech.
  • Emergency Zeroize: Clicking the red-bordered ZEROIZE button in settings immediately purges all keys globally from both client and server memory.
  • Vehicle Intercom (CH99 VIC): A local intercom wire. Channels set to CH99 VIC completely bypass all terrain, foliage, GPS, and atmospheric physics, guaranteeing 100% signal clarity ($1.0$ signal) at any distance or environment.
Note: Ensure the callsigns you create here exactly match the callsigns your users enter in the Launcher. It is case-sensitive.
