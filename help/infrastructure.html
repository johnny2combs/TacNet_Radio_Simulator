Network Infrastructure

Manage Retransmission (RETRA) nodes to extend radio range.

1. What is a Retrans Node?
In mountainous terrain, two handheld radios cannot communicate through solid rock. A Retrans Node acts as a bridge: placed on a high peak, it listens for a transmission on one channel and instantly rebroadcasts it, extending the line-of-sight network.
2. Deploying a Node
You can create a node here and assign it an MGRS coordinate, or simply create it and drag it into position on the Tactical Map. Assign it to specific channels so it only relays traffic intended for that net.
3. Environmental Penalties
Retrans nodes are subject to the same physics as operators. If a node is placed in a deep valley, it will not be able to relay effectively. Nodes also apply a slight latency penalty to audio packets passing through them.
4. Advanced Mesh Routing & Loop Protection
The TacNet server runs an advanced undirected mesh routing graph using a Breadth-First Search (BFS) routing algorithm:
  • Multi-Hop Relays: Audio packets automatically cascade through all configured retransmission pathways defined by the server's adjacency lists.
  • Anti-Loop Guard: Relayed packets are labeled with a " [R]" callsign suffix. Any incoming packet carrying this suffix is ignored for further retransmission, preventing feedback loops and network flooding.
Note: Nodes have their own TX Power and Antenna Height parameters. A node placed on a 30m tower will have vastly superior range to a node placed on the ground.
