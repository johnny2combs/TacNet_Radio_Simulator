Network Dashboard

Real-time overview of simulation health and connected clients.

1. Telemetry Metrics
The top grid displays live server performance metrics.
  • Clients Online: Number of actively connected operators.
  • Packets Relayed: Total voice audio chunks routed by the server today.
  • Packets Dropped: Audio discarded because the receiving client was out of radio range or jammed. High drop rates indicate a heavily contested RF environment.
2. Connected Clients Matrix
This table lists every operator currently authenticated.
  • MGRS: Their live GPS position on the grid.
  • Status: Green means stable socket connection. Yellow means intermittent packet loss.
  • Actions: You can forcibly kick a client from the server if they are stuck or unauthorized.
3. Live Network Activity
A scrolling event log of server-side operations, showing when clients join, leave, or change frequencies.
4. Command Diagnostics HUD Grid
Four premium tactical boards dynamically audit simulation physics and compliance:
  • Atmosphere & Terrain HUD: Monitors signal attenuation factors from active rain, urban terrain structures, temperature inversions (skipping terrain), and solar ionospheric activity.
  • EW & RF Threat Board: Active tracking of OPFOR jammer bubbles, background EMI levels, co-site frequency overlap hazards, and silenced EMCON nodes.
  • Real-time LQA Matrix: Live grid detailing exact node-to-node signal paths, mutual grid distances (km), and mesh hops (direct vs retrans repeaters).
  • PACE & COMSEC Auditor: Warns if a unit is assigned to SATCOM or HF bands but lacks the physical hardware antenna in their profile, and audits crypto key fills.
